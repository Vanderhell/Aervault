# Security policy

## Supported versions

Security fixes are provided for the latest release line. Aervault is currently
pre-1.0; public APIs and storage modules may change between minor releases.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or discussions. Use
GitHub's **Report a vulnerability** feature in the repository Security tab
when private vulnerability reporting is available. If it is unavailable,
contact the maintainer through the contact route on
https://github.com/Vanderhell and include steps to reproduce, affected commit,
and impact. Do not include real secrets or production data in the report.

The maintainer will acknowledge a report and coordinate a fix and disclosure
timeline with the reporter. There is no guaranteed response-time SLA yet.
